Password Reset Guide

If a user cannot access their account due to a forgotten password:

1. Click the "Forgot Password" link on the login page.
2. Enter the registered email address.
3. Check the inbox for a password reset email.
4. Follow the password reset link.
5. Create a new password that meets security requirements.

If the reset email is not received:
- Check spam or junk folders.
- Verify the registered email address.
- Wait up to 10 minutes for delivery.

If the issue persists, contact support.
